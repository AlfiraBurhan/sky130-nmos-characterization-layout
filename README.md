SKY130 NMOS Characterization and Layout

Three small, independent exercises built around the open-source SkyWater SKY130 process, done as part of my self-study in device characterization and layout:

Subthreshold swing extraction from a public measured NMOS transfer curve (Python).
A four-terminal NMOS layout drawn in KLayout, with a minimum-width DRC check.
A four-channel pass-through PCB adapter designed in AutoCAD and KiCad.
Scope: what this repository is and is not
The measured data in part 1 are public SKY130 measurement data, not data I measured. My contribution is the analysis.
Parts 1 and 2 are separate exercises. The layout is not claimed to correspond to the measured device.
The repository contains no circuit simulation, no low-temperature data, no LVS or parasitic extraction, and no fabricated or tested hardware.
Planned follow-up work is listed at the end and is not yet done.
